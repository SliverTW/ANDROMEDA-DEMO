# ANDROMEDA – spielbare Demo

**ANDROMEDA** ist ein Science-Fiction-Rollenspiel in Entwicklung. Du erkundest als Erik mit seinem Begleiter Nox die Piratenstadt Black Bay und das Raumschiff RUMO in Echtzeit, sprichst mit den Leuten, handelst, nimmst Aufträge an und kämpfst rundenbasiert – am Boden wie im Weltraum.

> ⚠️ **Frühe Demo.** Das Spiel ist nicht fertig. Inhalte fehlen, viele Grafiken sind Platzhalter, und es kann Fehler oder Ruckler geben. Rückmeldungen sind sehr willkommen!

Dieses Repository enthält **nur fertige Spielversionen zum Herunterladen** – keinen Quellcode. Entwickelt wird das Spiel in einem privaten Repository.

## ▶️ Starten (Windows)
1. `ANDROMEDA-Demo-Windows.zip` herunterladen.
2. Rechtsklick auf die ZIP-Datei → **„Alle extrahieren…“**. Nicht direkt aus der ZIP heraus starten.
3. Im entpackten Ordner **`ANDROMEDA.exe`** doppelklicken.
4. Meldet Windows „Der Computer wurde durch Windows geschützt“: **„Weitere Informationen“** → **„Trotzdem ausführen“**. Die Datei ist nicht digital signiert; das ist bei kleinen Hobbyprojekten üblich.

Es muss nichts installiert werden. Spielstände liegen unter `%APPDATA%\ANDROMEDA_Fable_Demo`.

Mehr Hilfe: [ANLEITUNG.md](ANLEITUNG.md)
